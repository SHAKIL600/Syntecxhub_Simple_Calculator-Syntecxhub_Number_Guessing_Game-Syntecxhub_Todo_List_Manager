## Push each project to GitHub
Create an empty repo on github.com with the exact name, then:
```bash
cd Syntecxhub_Simple_Calculator
git init
git add .
git commit -m "Add simple calculator with tests"
git branch -M main
git remote add origin https://github.com/<your-username>/Syntecxhub_Simple_Calculator.git
git push -u origin main
```
Repeat for the other two folders.
